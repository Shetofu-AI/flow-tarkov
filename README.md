# Flow Launcher: Tarkov

Плагин для [Flow Launcher](https://www.flowlauncher.com/): цены предметов Escape from Tarkov
прямо из строки запуска, без альт-таба в браузер. Данные — [tarkov.dev](https://tarkov.dev).

```
tk салева        →  Аптечка Salewa First Aid Kit
                    Salewa · барахолка 38 500 ₽ (19 250 ₽/слот) · Терапевт 12 000 ₽
```

`Enter` открывает страницу предмета на tarkov.dev, `Shift+Enter` (контекстное меню) копирует
цену или название и ведёт на вики.

## Поиск

Ищет по русскому названию, сокращению и английскому имени одновременно, так что
`ледкс`, `ledx` и `LEDX` находят одно и то же. Если ничего не нашлось, запрос ещё раз
прогоняется через смену раскладки: набранное вслепую `cfktdf` превращается в `салева`.

## Данные

Один GraphQL-запрос `items(lang: ru)` со всеми предметами и ценами, ответ кладётся в
`%APPDATA%\FlowLauncher.Tarkov\items.json`. Кэш живёт 30 минут: поиск всегда идёт по
локальной копии, обновление уходит в фон и не тормозит выдачу. `tk` без текста показывает
время последнего обновления и кнопку «Обновить цены сейчас».

Цены — режим PvP. Барахолка берётся из `lastLowPrice` (последнее минимальное предложение),
торговец — лучший из `sellFor` кроме самой барахолки.

## Сборка и установка

```powershell
.\build.ps1                          # собрать и положить в Flow Launcher, перезапустив его
.\build.ps1 -NoRestart               # без перезапуска
.\build.ps1 -PluginsPath "...\UserData\Plugins"
```

Скрипт сам находит папку плагинов: по запущенному процессу Flow, потом по портативной
установке в `D:\PortableApps\Portable FlowLauncher`, потом по `%APPDATA%\FlowLauncher`.

Нужен .NET SDK 9 или новее; плагин собирается под `net9.0-windows` — тот же рантайм,
что внутри Flow Launcher 2.x.
