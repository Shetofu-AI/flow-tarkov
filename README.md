# Flow Launcher: Tarkov

Плагин для [Flow Launcher](https://www.flowlauncher.com/): цены предметов Escape from Tarkov
прямо из строки запуска, без альт-таба в браузер. Данные — [tarkov.dev](https://tarkov.dev).

```
tk салева        →  Аптечка Salewa First Aid Kit
                    Salewa · барахолка 38 500 ₽ (19 250 ₽/слот) · Терапевт 12 000 ₽
```

`Enter` открывает страницу предмета на tarkov.dev, `Shift+Enter` (контекстное меню) копирует
цену или название и ведёт на вики.

## Поиск

Ищет по русскому названию, сокращению и английскому имени одновременно. Перед сравнением
и запрос, и названия сводятся к общему фонетическому ключу (кириллица транслитерируется,
`w`→`v`, `x`→`ks`, `c`/`q`→`k`, `y`→`i`, повторы схлопываются), поэтому одинаково работают
`ledx` и `ледкс`, `gpu` и `гпу`, `salewa` и `салева` — при том что в самой игре половина
названий латиницей. Если не нашлось ничего, запрос прогоняется ещё раз через смену
раскладки: набранное вслепую `cfktdf` превращается в `салева`.

Ранжирование не отдано на откуп нечёткому поиску: точное совпадение с сокращением или
названием идёт выше совпадения по началу слова, а нечёткий поиск Flow остаётся последним
резервом для опечаток. Без этого `gpu` выдавал Magpul вместо Видеокарты.

## Данные

Источник — JSON API `json.tarkov.dev`: `regular/items` (все предметы с ценами),
`regular/items_ru` и `regular/traders_ru` (названия предметов и торговцев по-русски,
в самих данных лежат только ключи локализации вида `<id> Name`).

Плоские файлы, а не GraphQL, выбраны намеренно: `api.tarkov.dev/graphql` объявлен legacy
и с 21.07.2026 отдаёт INTERNAL_SERVER_ERROR на любой запрос
([issue #474](https://github.com/the-hideout/tarkov-api/issues/474)), тогда как JSON API
живой — сайт tarkov.dev читает именно его.

Результат кладётся в `%APPDATA%\FlowLauncher.Tarkov\items.json` (~3.5 МБ, 5300 предметов).
Кэш живёт 30 минут, поиск всегда идёт по локальной копии, обновление уходит в фон.
Повторное обновление стоит один условный запрос: сохранённый ETag превращает его в 304
и 80 мс вместо полной перекачки. После ошибки следующая попытка не раньше чем через
30 секунд, чтобы набор текста не бил в упавший сервер. `tk` без текста показывает время
последнего обновления и кнопку «Обновить цены сейчас».

Цены — режим PvP (`regular`). Барахолка берётся из `lastLowPrice` (последнее минимальное
предложение), торговец — лучший из `sellToTrader`.

## Сборка и установка

```powershell
.\build.ps1                          # собрать и положить в Flow Launcher, перезапустив его
.\build.ps1 -NoRestart               # без перезапуска
.\build.ps1 -PluginsPath "...\UserData\Plugins"
```

Скрипт сам находит папку плагинов: по запущенному процессу Flow, потом по портативной
установке в `D:\PortableApps\Portable FlowLauncher`, потом по `%APPDATA%\FlowLauncher`.

Нужен .NET SDK 9 или новее; плагин собирается под `net9.0-windows` — тот же рантайм,
что внутри Flow Launcher 2.x.
